# repo1nvo

Aplicación web mínima para:

- Capturar pantalla en vivo (desde el navegador).
- Leer texto grande de resultados con OCR (Tesseract.js).
- Detectar multiplicadores tipo `1.45x`.
- Guardar historial local por ronda (`localStorage`).
- Mostrar recomendación simple: **APOSTAR** / **NO APOSTAR** según promedio reciente.

## Uso rápido

1. Abrir `index.html` en un navegador moderno (Chrome/Edge).
2. Pulsar **Iniciar captura** y compartir la pantalla/ventana del juego.
3. Dejar visible el resultado grande de cada ronda para que el OCR lo detecte.
4. Revisar historial y recomendación en la interfaz.

## Nota

La recomendación incluida es una regla base simple y no garantiza resultados.
